# Factory-to-customer-shipping-route-efficiency-analysis
This project analyzes shipping performance across factory-to-customer routes to identify inefficiencies, bottlenecks, and optimization opportunities. It uses a KPI-driven approach combined with an interactive Streamlit dashboard for data exploration.
- 🚀 Features
- 📊 KPI-driven analysis (Lead Time, Delay Frequency, Efficiency Score)
- 🌍 Geographic visualization of shipping performance (USA & Canada)
- 🚨 Bottleneck and congestion detection
- 🚚 Ship mode comparison (speed vs reliability)
- 🔍 Region & State level insights with drill-down
- 🎛️ Interactive dashboard filters (date, region, state, ship mode)
- 
## 🧠 Tech Stack
Python (Pandas, NumPy)
Plotly (Visualization)
Streamlit (Dashboard)
Mapbox (Geographic Mapping)

## 📊 Key Insights
Identifies high-performing and inefficient routes
Detects high-volume bottlenecks and congestion-prone regions
Highlights differences between regional and state-level performance
Evaluates effectiveness of different shipping modes

## 🎯 Outcome
Enables a shift from reactive logistics management to data-driven decision-making by providing clear visibility into delivery performance and operational inefficiencies.
